# 🍔 Projeto em destaque — Smart Burguer

## Sistema Full Stack para gerenciamento de hamburgueria

O **Smart Burguer** é uma aplicação Full Stack desenvolvida para simular um sistema real de gerenciamento de pedidos de uma hamburgueria.

### 🎨 Front-end

**React + TypeScript + Tailwind CSS**

Principais funcionalidades:

- Catálogo de produtos
- Categorias de produtos
- Carrinho de compras
- Controle de quantidade
- Cadastro de usuários
- Login
- Gerenciamento de pedidos
- Alteração de status dos pedidos
- Interfaces responsivas
- Integração completa com API REST

### ⚙️ Back-end

**Node.js + Express + TypeScript**

Implementação de:

- API REST
- Controllers
- Routes
- Middlewares
- Autenticação JWT
- Cookies
- Controle de usuários
- Controle administrativo
- Regras de negócio
- Carrinho de compras
- Produtos
- Pedidos
- Upload de imagens
- Tratamento de erros
- Swagger / OpenAPI

### 🗄️ Banco de Dados

**PostgreSQL + Prisma ORM**

Modelagem envolvendo:

`Usuários → Carrinho → Produtos → Pedidos → Itens do Pedido`

### 🐳 Infraestrutura

O ambiente da aplicação utiliza:

**Docker + Docker Compose**

com containers para aplicação, banco de dados e ferramentas auxiliares.

### 🔧 Stack

`React` • `TypeScript` • `Tailwind CSS` • `Node.js` • `Express` • `Prisma` • `PostgreSQL` • `JWT` • `Swagger` • `Docker`
